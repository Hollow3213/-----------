# Task Tracker — проектирование

## Технологии и инструменты

### HTML-шаблонизация
- Отдельный HTML-шаблонизатор (Nunjucks и аналоги) — пока не используем.
- Для динамического создания и обновления интерфейса в перспективе будем использовать React и JSX.
- Повторяющиеся элементы интерфейса будем оформлять в виде React-компонентов с возможностью передачи данных и управления состоянием.

### SCSS
- Пока не является обязательной технологией проекта.
- Основная система стилей — современный CSS.
- Возможность перехода на SCSS оставляем на будущее, если появится реальная необходимость.
- Перед внедрением необходимо закрепить базовый CSS.

### Vite
- Планируется к использованию при переходе к более сложной разработке на JavaScript, React и TypeScript.
- Работа с npm-пакетами и зависимостями.
- Сборка проекта для публикации.
- Минификация и оптимизация ресурсов.
- Tree Shaking.
- Поддержка React, TypeScript и SCSS.
- На начальном этапе HTML/CSS можно разрабатывать с помощью Live Server.
